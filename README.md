# Система управления мобильным роботом на базе ROS 2 и Docker

Данный проект представляет собой программный комплекс для управления мобильным роботом, сбора телеметрии с сенсоров и визуализации данных. Система полностью контейнеризирована с помощью Docker, что обеспечивает быструю разворачиваемость на любом оборудовании без необходимости ручной установки ROS 2.

---

## 1. Архитектура и функции системы

Программная архитектура построена на базе **ROS 2 Humble** (дистрибутив `desktop`). Основным управляющим элементом является узел `robot_controller_node`, написанный на Python (`rclpy`).

### Функции системы:
* **Сбор и обработка данных** с четырех разнородных датчиков робота в реальном времени.
* **Автоматический обход препятствий** на основе анализа данных лазерного сканирования.
* **Экстренная диагностика стабильности** платформы по показаниям инерциального датчика.
* **Формирование и отправка команд** на исполнительные устройства (моторы) с частотой 10 Гц.

### Поддерживаемые датчики и устройства (4 датчика + 1 привод):
1. **LIDAR (Лазерный дальномер)** — топик `/scan`, тип сообщения `sensor_msgs/msg/LaserScan`. Используется для определения расстояния до препятствий.
2. **IMU (Инерциальный датчик)** — топик `/imu`, тип сообщения `sensor_msgs/msg/Imu`. Отслеживает угловые скорости и линейные ускорения робота.
3. **Camera (Видеокамера)** — топик `/camera/image_raw`, тип сообщения `sensor_msgs/msg/Image`. Обеспечивает передачу сырого видеопотока.
4. **Custom Sensor (Стороннее устройство)** — топик `/custom_sensor/data`, тип сообщения `std_msgs/msg/Float64`. Воркспейс ROS 2 подготовлен под сборку данного кастомного пакета (`diagnostics`) напрямую из исходных кодов с помощью `colcon build`.
5. **Motor Controller (Привод колес)** — исполнительное устройство, топик `/cmd_vel`, тип сообщения `geometry_msgs/msg/Twist`. Принимает команды линейной и угловой скорости.

## 2. Структура проекта

Проект организован в строгом соответствии с требованиями практического задания к модулю 4:

```text
robot_control_project/
├── docker/
│   ├── Dockerfile       # Конфигурация Docker-образа, сборка пакетов из исходников
│   └── entrypoint.sh    # Скрипт автоматической подгрузки окружения ROS 2
├── scripts/
│   ├── build.sh         # Bash-скрипт для сборки Docker-образа
│   └── run.sh           # Bash-скрипт для запуска контейнера с поддержкой GUI (X11)
├── src/
│   └── motor_control.py # Основной исполняемый скрипт узла управления роботом
└── README.MD            # Документация и инструкции по использованию проекта
```

## 3. Решение проблемы графических приложений (GUI в Docker)

Поскольку такие инструменты, как `rviz2` или `rqt`, требуют доступа к графической карте и экрану хост-компьютера, в проекте реализовано типовое решение проблемы **"gui in docker"**. 

В скрипте запуска `scripts/run.sh` автоматически выполняются следующие действия:
* Команда `xhost +local:docker` временно разрешает контейнерам подключаться к X-серверу хоста.
* Переменная окружения `DISPLAY` пробрасывается внутрь контейнера через флаг `--env`.
* Локальный сокет X-сервера монтируется внутрь контейнера как изолированный том: `--volume="/tmp/.X11-unix:/tmp/.X11-unix:rw"`.
* Для предотвращения ошибок разделяемой памяти QT используется флаг `--env="QT_X11_NO_MITSHM=1"`.

## 4. Инструкция по установке, настройке и использованию

### Шаг 1. Сборка Docker-образа
Скрипт автоматически развернет операционную среду, перенесет локальные исходники пакетов и подготовит рабочее пространство ROS 2:
```bash
sudo ./scripts/build.sh
```

### Шаг 2. Запуск системы управления роботом
Запустите скрипт управления. Он настроит права графического дисплея и активирует управляющую ноду:
```bash
sudo ./scripts/run.sh
```
В терминале отобразится лог успешного старта:
`[INFO] [robot_controller_node]: === Система управления роботом успешно инициализирована ===`

### Шаг 3. Запуск утилит визуализации (GUI)
Пока робот запущен и активен в первом терминале, откройте **второе (новое) окно терминала** и выполните команду для открытия RViz2 внутри контейнера:
```bash
sudo docker exec -it robot_control_container bash -c "source /opt/ros/humble/setup.bash && rviz2"
```
Программа успешно откроется в графическом окне вашей основной ОС Ubuntu без каких-либо ошибок доступа к экрану.
